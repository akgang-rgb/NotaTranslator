Tutoriel · 10 minutesConfigurer Discord

Facultatif, désactivé par défaut. Archè peut lire vos propres salons via un bot que vous créez, uniquement pour enrichir votre pile de propositions. Le bot ne lit que les salons que vous listez — et n'envoie rien nulle part.

Principe de base : l'extension ne crée aucun compte Discord et n'utilise aucun service intermédiaire. C'est votre bot, sur votre serveur, avec vos salons. Voyez-en la portée dans la politique de confidentialité (section Discord).

Étape 1 — Créer l'application

  1. Ouvrez discord.com/developers/applications et connectez-vous avec votre compte Discord.
  2. Cliquez New Application, donnez-lui un nom (ex. Archè Lecteur), acceptez les conditions.

Étape 2 — Créer le bot

  1. Dans l'application, ouvrez l'onglet Bot (menu de gauche).
  2. Cliquez Reset Token puis Copy : c'est le jeton du bot. Il sera collé dans Archè à l'étape 5.
  3. Toujours dans l'onglet Bot, descendez dans Privileged Gateway Intents et activez Message Content Intent. Sans cet intent, Discord n'envoie le bot que des messages vides — c'est l'erreur n°1.
Le jeton, c'est la clé du bot. Ne le partagez jamais (ni dans un salon, ni dans une capture d'écran). S'il fuite : Reset Token dans le portail développeurs, puis recollez le nouveau jeton dans les réglages d'Archè. La valeur est stockée dans le coffre chiffré de l'extension, jamais en clair.

Étape 3 — Inviter le bot dans votre serveur

  1. Toujours dans l'application, ouvrez OAuth2 → URL Generator.
  2. Dans Scopes, cochez bot.
  3. Dans Bot Permissions, View Channels (« Voir les salons ») suffit.
  4. Copiez l'URL générée en bas de page, ouvrez-la dans votre navigateur, choisissez votre serveur et autorisez.

Étape 4 — Récupérer les identifiants de salons

  1. Dans Discord, activez le mode développeur : Réglages utilisateur → Avancé → Mode développeur.
  2. Clic droit sur chaque salon à suivre → Copier l'identifiant. Vous obtenez un long nombre (ex. 112233445566778899).
  3. Notez-les : un identifiant par ligne, ils seront collés à l'étape 5.

Étape 5 — Brancher Archè

  1. Ouvrez les réglages d'Archè (clic sur l'icône → Options), section Sources sociales.
  2. Collez le jeton du bot dans Discord — jeton de bot.
  3. Collez les identifiants de salons dans Discord — canaux suivis, un par ligne.
  4. Enregistrer. Lors de l'enregistrement, l'extension demande l'autorisation d'accéder aux sites : acceptez (requis pour lire l'API Discord).

Si ça ne fonctionne pas

Salon lu mais rien ne tombe

Vérifiez Message Content Intent (étape 2) — sans lui, les messages sont vides et aucun lien n'est extractible.

Le bot ne voit pas le salon

Permission View Channels manquante à l'invitation, ou salon privé non visible. Réinvitez avec la bonne permission.

Erreur 401

Jeton invalide ou régénéré. Recopiez le jeton courant depuis le portail développeurs dans les réglages d'Archè.

Mauvais identifiant de salon

Un ID de salon, pas de serveur ni de message. Recopiez via clic droit → « Copier l'identifiant » avec le mode développeur activé.
