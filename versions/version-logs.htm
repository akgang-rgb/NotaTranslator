Version logs

A simple history of changes and improvements to Not a Translator.

8.3.xx

  • “More…” link now points to Wikipedia.
  • The dictionary definition page can be opened from the dictionary icon on the left side of the tooltip, just before the definition.

8.2.70

Fixes and minor improvements.

8.2.65

  • Hook for the companion app.
  • New units parsed by the conversion tool.

Notatr. Experiment 0.1.86

  • Donors-only satellite / companion extension.
  • Definition thumbnails.
  • SenseMap: a visual map of synonyms, antonyms, hyperonyms, co-hyponyms and meronyms/holonyms.
  • Rootmap: a similar view focused on etymology and word families.

8.2.31

  • German language added for the UI.
  • Words can be looked up in another language from an article and defined in English.
  • Caching and versioning for frequently used definitions across dictionaries.
  • Improved handling when the system cannot determine the best definition.
  • New expressions recognised for unit and time conversions.

7.2.2

  • Fixed language detection on certain sites.
  • Added psi ↔ bar conversion.
  • Revised miles conversion.
  • Enhanced temperature parsing.
  • Added support for selections such as “400-square-foot” in conversion parsing.

7.1.6

  • Enhanced the Italian dictionary.
  • Enhanced the English dictionary.
  • Enhanced temperature conversion.

7.1.2

Enhanced the French dictionary.

7.1.0

Minor enhancement to English definition lookup.

7.0.7

Rendering enhancement, including menu scrolling.

7.0.3

  • Added “Buy me a coffee”.
  • Minor rendering fixes.

7.0.2

  • Added the temperature conversion button to console mode when selecting a temperature such as “15°” without specifying Fahrenheit or Celsius.
  • Removed the Imperator button.

7.0.0

  • Added more measurement units, including biblical and archaic units in supported locales, plus several imperial units.
  • Minor bug fixes.
  • Improved SVG button rendering in the toolbar inside tooltips.

6.8.4

  • Rendering fixes.
  • Introduction of the infamous tooltip Imperator.

6.7.1

  • Finnish dictionary added.
  • Full tokenisation and lemmatisation.

6.0

  • Greek/Latin translation in the detected local language through Logeion.
  • Active translation for new dictionaries, with load balancing between several translation servers.
  • Cambridge replaced by Merriam-Webster because of access restrictions; a free fallback is used when the quota is reached.
  • German dictionary changed to DWDS, with improved retrieval of compound words.
  • Cascading fallback dictionaries.
  • Improved timezone and measurement-unit detection.
  • Improved UI and console controls.
  • Audio rendering.
  • Fixes and improved tooltip rendering on certain sites.

5.0

Introduced a failsafe console for storing tips on exotic or JavaScript-hostile sites.

4.0

  • Conversion tool for time and measurements.
  • Local time detection through the browser.

3.0.1

  • Opacity slider added.
  • Dictionaries and word sorting revised.
  • Cambridge dictionary access fixed/reworked after a site change.
  • Bug fixes and rendering improvements.
  • AI-assisted coding was used for this release.

2.9

  • Bug fixes and improved language detection management.
  • Quick translation added.
  • Improved multi-tab language detection.
  • German and Italian dictionaries added.
  • Language autodetection can be disabled.
  • Language autodetection is automatically disabled when changing dictionary.
  • Donation through Leetchi.
  • Appearance improvements.

Earlier releases

  • 2.1: remove-tooltip feature.
  • 1.8: language autodetection.
  • New dictionaries added over time.

Still no ads and no tracking. Data gathered through the browser is used by the autodetection tools, such as language and time detection.
