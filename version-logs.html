Version logs

Changes to Not A Translator and its companion extensions. Some older changes are grouped by version series where the exact patch number was not recorded. Availability may differ between browser stores.

Not A Translator

9.1.20

  • Safari: the Image button now follows the tooltip text color in normal and anti-clipping mode, including white on purple.
  • Protected the image icon against page styles while preserving its frame cutout, loading spinner and red unavailable indicator.

9.1.19Includes updates since 9.1.16

  • Firefox desktop: refined the black tooltip header with three right-aligned controls and immediate width synchronization. Improved white SVG icons while preserving their cutouts.
  • Firefox desktop: improved anti-clipping tooltip headers and conversion bubbles, keeping results separate from the controls and protecting minimum height and text wrapping.
  • Firefox desktop: added a short hover grace period to reach the tooltip. Clicking the rotation control no longer leaves normal and conversion tooltips permanently visible after the pointer moves away; keyboard focus remains supported.
  • Safari: pronunciation uses Web Audio in normal tooltips, anti-clipping tooltips and the console to reduce interruptions to audio playing in another app. The console now activates audio during the click, before looking up a missing audio URL. A legacy audio fallback remains available.

9.1.16

  • Fixed the first-click failure in anti-clipping tooltips: moving focus to a button no longer dismisses the tooltip before its action runs.
  • Improved independent tooltip state, deletion and cleanup, with four clockwise positions and an accessible inline rotation control.
  • Harmonized hide timers and busy-action behavior across Chrome, Safari, Firefox and Firefox Android.
  • Hardened SVG colors, outline spinners and toolbar controls against page styles. Preserved compact wrapping and the tooltip tail in overlay mode.
  • Restored pronunciation playback on pages that block remote media, using the extension audio retrieval and Blob path in both normal and anti-clipping tooltips.
  • Stabilized page-language detection: visible content is counted once, navigation and injected tooltips are excluded, and stale results are ignored.
  • Preserved preferences during updates and made lookup wait for ready page hooks. Fixed competing language-state updates between tabs.
  • The browser badge turns orange when anti-clipping mode or a console prompt is needed. A prompt caused only by an anchor pushing a selection onto the next line keeps the existing badge color.
  • The anti-clipping asterisk is now debug-only; debug mode is disabled in normal builds.

9.1.xOther series updates

  • Refined Chrome and Safari tooltips with a black header, separate upper controls and a more spacious lower toolbar.
  • Gave small conversion tooltips enough height to keep their text clear of the upper controls.
  • Refined popup text readability with a hover-only background veil. Updated Chrome wallpapers to PNG while leaving other platforms' wallpaper sets unchanged.
  • Reviewed interface translations and retained readable English HTML fallbacks when localization is unavailable.
  • Improved AI provider ordering and the persistence of linear or circular selection, with provider help and status messages.

9.1.13

  • Made image-search translation resilient to Google Translate rate limits: try LibreTranslate, then AI when authorized, then search with the source word.
  • Stop unnecessary retries after HTTP 429 without adding quota warnings to the normal tooltip.
  • Applied the fallback behavior across Chrome, Safari, Firefox desktop and Firefox Android.

8.3.xSeries updates

  • The More... link opens Wikipedia. The dictionary icon immediately before the definition opens the original dictionary entry.
  • Added and refined optional AI-assisted definitions and companion features, with Eco and Full modes and configurable providers.
  • Improved AI dictionary fallback, translate-anyway requests, map candidate filtering and warnings for AI-added etymons.
  • Refined provider testing, model-response handling and saved provider order. Missing quota information is not presented as a known balance.

8.3.18

  • Added a targeted Merriam-Webster Collegiate fallback for compound words missing from the Learner's dictionary, where the corresponding API route is available.
  • Rejected unrelated suggestions that merely share a prefix, while preserving ordinary phrasal-verb and single-word lookup behavior.
